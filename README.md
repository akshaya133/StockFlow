# StockFlow – Inventory Management System

🚀 **Live Demo:** https://stock-flow-plum-chi.vercel.app/login

StockFlow is a multi-tenant SaaS inventory management application that helps organizations manage their products and monitor stock levels.

### Key Features
- User signup and login with JWT authentication.
- Organization-based inventory management.
- Add, view, update and delete products.
- Track product quantities and prices.
- Low-stock alerts based on custom thresholds.
- Dashboard with inventory statistics.

### Tech Stack
- **Frontend:** React.js, Vite
- **Backend:** Node.js, Express.js
- **Database:** PostgreSQL (Neon)
- **Authentication:** JWT and bcrypt
- **Deployment:** Vercel and Render
